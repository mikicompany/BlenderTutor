One-time setup — connect your testimonials sheet

This lets the editor save straight to your site. Takes about 3 minutes, once.

  1. Open your Testimonials sheet, then click Extensions → Apps Script.
  2. Delete whatever is there, paste the code below, and click Save (💾).
  3. Click Deploy → New deployment. For type choose Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy.
  4. Google will ask you to authorize — allow it (click Advanced → Go to … (unsafe) if warned; it's your own script).
  5. Copy the Web app URL (it ends in /exec) and paste it below.
